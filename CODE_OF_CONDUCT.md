# Code of Conduct

We want this project to be a respectful, evidence-oriented place to collaborate.

## Expected behavior

- Discuss ideas and evidence without attacking people.
- Be clear about uncertainty, limitations, and the scope of a claim.
- Respect privacy, confidentiality, and intellectual property.
- Accept correction when tests or reproducible evidence contradict an assertion.

## Unacceptable behavior

Harassment, discrimination, threats, publishing private information, deliberately bypassing the repository's disclosure boundary, or misrepresenting this project as an official institutional product are not acceptable.

## Enforcement

Report conduct or security concerns privately through the contact route in [SECURITY.md](SECURITY.md). Maintainers may edit or remove content and restrict participation when necessary to protect participants and the project.

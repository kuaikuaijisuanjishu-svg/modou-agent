# 水木验码 v0.2 公开预览版

水木验码 v0.2 公开预览版提供围绕代码改动的测试证据检查、缺口处置和版本复验流程。

本版包含：

- 在本地工作台查看验收目标、实验依据、当前版本及下一步操作；
- 将测试缺口连接到候选验证、用户采用和新版本复验；
- 保留任务轮次和历史结果，代码变化后重新检查依据；
- 通过有限期授权和显式检查事件组织复验，展示作业进度、停止和恢复状态；
- 通过 CLI、MCP 与 VS Code 接入，共用本地任务和回执。

请从本页面的 Release assets 下载对应平台的包，并在安装前核对 SHA-256。macOS 包已完成安装脚本、包完整性和确定性演示核验；Windows 包的后端运行在 WSL2，仍属于待目标机器验证的预览。

这是实验预览版，不承诺任意项目、语言或环境均适用。模型功能需要用户自行配置服务和凭据；部分任务可能因映射不明确、环境异常或证据不足而需要人工处理。

反馈时请提供最小复现和脱敏日志，不要上传私人源码、密钥或含令牌链接。敏感问题请按 [SECURITY.md](../../SECURITY.md) 中的私密渠道处理。

# 水木验码 v0.2.0-experimental.1

这是公开实验版（experimental / opt-in），不是 stable、generally available 或
production-ready 发布。候选修复、Vitest/Jest 适配器和其他新增能力默认关闭，
只在明确选择启用且用户信任仓库、隔离环境时运行。

本版本的公开树来自经过脱敏检查的固定提交。发布证据只支持仓库内机器回归；
不支持第三方仓库兼容性、任意仓库推广、语义等价、安全删除或自动 push、
merge、publish。

本版本未完成独立隐藏 QA、授权私库灰度、真人开发者研究和 stable 所需的人工
安全签字。计划中的 10 个 AI+Skill 合成候选 session 不是人类参与者，并且本次
没有完成执行；不能把它们解释为真人用户研究、人因结论或安全放行证据。

公开仓库 product-off/product-on 试点没有完成。两次方法批次均在正式六库分母
冻结前作废，第二次预检只得到 Python 0 个、Vitest 0 个、Jest 1 个合格候选，
因此不存在可用于兼容性声明的固定六库样本，也没有运行正式 product-on 对照。
`timkindberg/jest-when` 仍明确记录为
`REPOSITORY_INELIGIBLE / license_predicate_unverified`，没有从候选历史中静默删除。
本版本不宣称通过了 6/6，不宣称兼容 pytest、Vitest 或 Jest 仓库，也不把预检
失败解释为产品不兼容。

实验版不承诺固定修复时限。发现安全问题时，请使用仓库的 GitHub Private
Vulnerability Reporting；非敏感问题可提交最小化公开 issue，不要附带凭据、私有
路径、私有源码或内部日志。维护者可能先撤回 Release、关闭受影响能力，再发布
修复版本。

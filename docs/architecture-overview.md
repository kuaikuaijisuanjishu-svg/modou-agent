# 水木验码公开版架构总览

这份文档只描述公开展示包中可运行的边界，不代表私有研发工作区的完整实现。

```text
浏览器 Review Cockpit
        │  同源请求 + 一次性启动令牌
        ▼
本地控制面（FastAPI）
        │  只接受已授权仓库、相对测试路径和固定执行器
        ├──────────────► 计划与人工批准
        │
        ▼
隔离工作区 / 测试子进程
        │  建立基线 → 临时干预 → 重跑声明测试 → 恢复校验
        ▼
确定性证据面
        │  测试状态、覆盖、Git、AST、恢复状态
        ▼
ReviewBundle（可下载、可回放）
```

## 边界与责任

| 组件 | 公开职责 | 明确不做什么 |
| --- | --- | --- |
| Review Cockpit | 展示计划、批准入口、实验时间线、三态结果和证据 | 不直接执行任意浏览器输入中的命令 |
| 本地控制面 | 校验令牌、来源、仓库白名单、测试路径和能力状态 | 不向浏览器暴露本地绝对路径或密钥 |
| 隔离工作区 | 在临时 Git worktree 中运行可恢复实验 | 不修改用户原始工作树 |
| 测试子进程 | 运行仓库声明的 Python/pytest 测试 | 不把模型输出当作测试事实 |
| 证据面 | 生成具名测试、覆盖和恢复事实 | 不声称语义等价、可安全删除或绝对正确 |
| ReviewBundle | 保存事件、报告、账本和回放所需的聚合证据 | 不包含源码正文、原始模型响应或内部历史材料 |

## 公开运行资源边界

公开版当前把这些边界作为运行契约；没有实现的项目必须保持“未实现”口径，不用文案代替限制。

| 资源 | 当前公开承诺 | 验证位置 |
| --- | --- | --- |
| 网络 | 本地回环服务；公开演示不需要模型 API | `modou/server/__main__.py`、公开流程测试 |
| 测试范围 | 只运行服务端登记且仓库内的相对 pytest 路径 | `modou/server/control.py`、服务边界测试 |
| 工作区 | 临时 worktree；实验结束执行恢复和干净状态校验 | `modou/workspace.py`、公开 smoke 测试 |
| 时间与次数 | 由请求预算和执行策略控制；耗尽后停止 | `modou/budget.py`、核心测试 |
| 磁盘、内存、进程数 | 未在公开版承诺硬上限 | 作为后续隔离升级项，不写成已支持能力 |
| 任意陌生仓库 | 不承诺安全执行 | `docs/security-boundary.md` |

## 证据生命周期

1. 服务端接受公开仓库别名和测试范围，生成计划草案。
2. 人工确认计划指纹后，才会开始执行实验。
3. 每次干预只在临时工作区发生，测试状态和恢复状态都进入事件流。
4. 结论由确定性代码根据事实生成；模型（若配置）不能写入 verdict。
5. 完成后生成 ReviewBundle，界面展示的摘要与下载内容来自同一份证据。

任何阶段失败都应失败关闭：不生成看似成功的结果，也不把缺少证据解释成“没有问题”。

# 隐私与数据处理

- 本地后台默认只监听回环地址，并使用启动令牌保护请求。
- 标准确定性路径不调用模型；启用模型能力时，选定的代码或测试内容可能发送给你配置的模型服务。
- 模型服务的网络、计费、保留和跨境处理规则由你选择的服务商决定；请先确认其条款和数据范围。
- 不要提交无权共享的代码、个人数据、凭据或含令牌的 URL。
- 诊断、回执和证据可能包含文件名、源码片段、测试名称和环境信息。提交问题前请脱敏。
- 公开包不包含 Git 历史、内部证据、私人项目、日志缓存、虚拟环境或密钥。

发现疑似凭据泄漏时，应先撤销或轮换凭据，再按 [SECURITY.md](../SECURITY.md) 的私密渠道报告；不要只删除文本后继续传播。

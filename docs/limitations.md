- v0.2 是实验预览版，不承诺任意项目、任意语言、任意测试框架或全部编辑器环境。
- 能执行某种语言的测试，不代表已经具备该语言的完整归因和修复能力。
- 目标映射不明确、环境异常、依赖缺失或证据不足时，结果可能是不可判定，需要人工处理。
- 候选通过验证不代表已采用；采用后仍需针对新版本重新验收。
- 持续委托按显式事件触发，不是后台持续扫描，也不会自动替你推送、合并或发布代码。
- Windows 后端依赖 WSL2；未完成目标机器验收前，Windows 包只作为未验证预览。
- 模型能力需要你自行配置服务、网络和预算，模型服务可能产生额外费用。
- 任何结果都只适用于本次代码、测试范围和环境，不应解释为“没有 bug”的证明。

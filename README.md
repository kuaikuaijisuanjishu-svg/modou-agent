# 水木验码

**面向 AI 编程的测试证据验证工具。** 水木验码围绕你关心的要求组织检查，查看现有测试提供了什么依据；发现缺口后组织补证，并在代码变化后继续复验。

当前版本：**v0.2 实验预览版**。它适合在可信项目和可恢复的工作副本中试用。测试通过、实验支持与功能完全正确不是同一件事；结果应结合本次检查范围理解。

## 可以做什么

- **审查当前改动**：查看代码改动与相关测试的实验依据，区分有支持、缺少依据和暂时无法判断。
- **查看与导出证据**：在本地工作台阅读逐行结果、实验记录及版本相关回执。
- **处置测试缺口**：准备或接收补测候选，在隔离环境验证，再由用户确认是否采用。
- **复验新版本**：采用候选或修改代码后重新检查，保留轮次与历史结论，避免把旧版本依据直接当作当前结论。
- **按授权接续验收**：在指定期限、次数和预算内，通过显式检查事件组织复验；可以查看进度并请求停止。
- **连接编程工具**：通过 CLI、MCP 或 VS Code 入口访问同一本地后台，查询任务、取得回执，并在已有授权内发起检查。

不同语言、测试框架和入口的支持深度有所不同，以随版本提供的能力状态和限制说明为准。能执行某种语言的测试，不等于已经具备所有实验归因能力。

## 一个典型流程

1. 选择已登记的项目和本次改动，写下你关心的验收要求。
2. 查看并确认检查计划。
3. 阅读结果：哪些要求有依据，哪些仍有缺口，哪些因环境或执行问题不能判断。
4. 对缺口准备补测候选，验证后决定是否采用。
5. 对当前代码重新验收，保存对应版本的结果。
6. 如需继续开发，可创建有限期委托，在后续改动完成时再次发起检查。

例如：“同一学号重复报名，不能增加第二条记录或重复扣除名额。”这是一条具体要求；一次检查的结果不代表整个报名系统没有问题。

## 下载与安装

请从 [GitHub Releases](../../releases/latest) 下载与你的平台对应的公开预览包，并在安装前核对 Release 页面列出的 SHA-256。当前公开预览标签为 `v0.2.0-experimental.1`；源码仓库不存放构建 ZIP。

- [macOS 安装说明](docs/install-mac.md)
- [Windows + WSL2 安装说明](docs/install-windows.md)
- [快速上手](docs/quickstart.md)
- [CLI / MCP / VS Code 接入](docs/integrations.md)

Windows 后端运行在 **WSL2 Linux 环境** 中；这不是无需 WSL 的原生 Windows 后端。Windows 包在目标机器未完成实测前，应保持“未验证预览”标识。

首次安装需要下载依赖。安装完成后的预置确定性演示不需要模型 API；调用模型的功能需要另行配置服务、网络和相应费用预算。

前端组件 `web/` 的版本为 **0.2.0**，使用 Apache-2.0 许可证，与仓库根目录的 [LICENSE](LICENSE) 一致；`private: true` 仅用于防止误发布到 npm，不改变源码许可。

## 模型与数据

标准确定性路径可不调用模型。启用模型能力前，请阅读界面中的授权和数据范围说明；选定代码内容可能发送给你配置的模型服务。不要向模型提交无权共享的代码或凭据。

本地后台使用访问令牌。不要分享含令牌的地址、配置文件或未经检查的诊断日志。诊断与证据中可能包含文件名、源码片段或环境信息，提交问题前请先脱敏。

## 当前限制

- 这是实验预览版，尚不承诺任意项目、任意语言或全部编辑器环境都可用。
- 目标映射不明确、环境异常或证据不足时，系统可能需要人工确认或返回不可判定。
- 候选通过验证不代表已采用；采用也不代表新版本已获得支持，需继续复验。
- 持续委托按显式事件触发，不等于后台持续扫描所有文件或任意自动修复。
- 请求停止后应等待执行停止确认；出现待恢复状态时，先处理恢复再继续操作。
- 不应将本工具结果视为“没有 bug”的证明。

完整的边界、隐私和反馈要求见 [隐私与安全](docs/privacy.md)、[限制](docs/limitations.md) 和 [SECURITY.md](SECURITY.md)。
